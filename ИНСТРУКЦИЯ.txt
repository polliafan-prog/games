КАК УСТРОЕН САЙТ
index.html  — сам сайт (его трогать не нужно)
games.js    — список игр и настройки (его вы дополняете)
Все остальные файлы (картинки, видео, презентации, PDF) лежат рядом, без папок.


КАК ВЫЛОЖИТЬ НА GITHUB PAGES
1. Создайте на GitHub новый репозиторий, например «games».
2. Нажмите Add file → Upload files и перетащите туда все файлы сайта.
3. Settings → Pages → Branch: main → Save.
4. Через пару минут сайт откроется по адресу polliafan-prog.github.io/games


КАК ДОБАВИТЬ НОВУЮ ИГРУ
1. В репозитории нажмите Add file → Upload files → загрузите фото/видео игры.
   Называйте файлы латиницей без пробелов: zima-1.jpg, zima.mp4
2. Откройте games.js → значок карандаша (Edit).
3. В начале файла есть ШАБЛОН. Скопируйте его и вставьте в список GAMES, заполните поля.
4. Внизу нажмите Commit changes. Через 1–2 минуты игра появится на сайте.

Важное в полях:
  price: 500   — цена; 0 — бесплатно; null — «цена уточняется»
  format: 'ppt'      — игра в PowerPoint;  'browser' — браузерная
  brand: 'logos'     — игра бренда @logos; 'own' — ваша
  link: 'igra.html' — для бесплатной игры: файл или ссылка, по которой её можно сразу забрать
  tags: ['Звук Р', 'Слова'] — теги. По ним игра сама попадает в нужный раздел:
      «Звук Р» → раздел «Звуки» и кнопка «Р»; «Небылицы», «Рассказ», «Предлоги» → «Связная речь»;
      «Внимание», «Память» → «Внимание и память»; «Слоговая структура»; «Диагностика».
      artic: true → раздел «Артикуляция».
  Каждая игра заканчивается на  },  (с запятой)

КАК СДЕЛАТЬ ИГРУ БЕСПЛАТНОЙ, ЧТОБЫ ЕЁ ЗАБИРАЛИ СРАЗУ
1. Самый простой способ — положить файл игры прямо на сайт, на сайт:
   в репозитории нажмите Add file → Upload files → загрузите файл
   (браузерная игра: igra.html; PowerPoint: igra.pptx; имя латиницей, без пробелов).
   Если файл больше 25 МБ, GitHub его не примет — тогда загрузите на Яндекс Диск
   или Google Диск и включите «Доступ по ссылке».
2. В games.js у этой игры поставьте  price: 0,  и вставьте ссылку:
     link: 'igra.pptx',          — если файл загружен на сайт
     link: 'https://disk.yandex.ru/...', — если на Яндекс Диске
3. На карточке появится зелёная кнопка «Забрать». Заявку заполнять не нужно.
Если у бесплатной игры нет ссылки, её можно добавить в заметки и запросить через заявку, как платную.

Чтобы изменить цену или описание — так же откройте games.js, поправьте и сохраните.
Если что-то сломалось, можно просто прислать games.js в чат Claude.


КАК ПОДКЛЮЧИТЬ ОТПРАВКУ ЗАЯВОК В TELEGRAM
1. В Telegram откройте @BotFather → /newbot → придумайте имя бота.
   BotFather пришлёт токен, длинную строку вида 7412345678:AAH...
2. Найдите своего нового бота и нажмите «Старт» (иначе он не сможет вам писать).
3. Откройте @userinfobot → «Старт». Он пришлёт ваш ID (число).
4. В games.js в самом верху впишите токен ДВУМЯ частями — до двоеточия и после:
     токен 7412345678:AAHabc...  →  telegramBotToken: ['7412345678', 'AAHabc...'],
     telegramChatId:   'ваш ID',
5. Сохраните. Теперь заявки будут приходить вам от этого бота.

Токен виден в коде сайта. Заведите отдельного бота только для заявок.
Если начнёт приходить спам, в @BotFather выберите бота → Revoke token и впишите новый.
